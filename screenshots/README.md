# Screenshots

This directory contains screenshots and demo images for the Unsplash Photo Downloader project.

## Files

- `demo.png` - Main application screenshot showing the search interface, results grid, and download progress

## How to Add Screenshots

1. Take a screenshot of the application (from browser or Vercel preview)
2. Save it as `demo.png` in this directory
3. Recommended size: 1920x1080 or similar aspect ratio
4. Commit and push to GitHub

## Screenshot Guidelines

- Show the main features: search bar, image grid, download progress
- Use high resolution for clarity
- Consider taking multiple screenshots for different states (search, results, downloading)
